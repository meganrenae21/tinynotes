##### The Build and Back-End

- Built with [11ty](https://11ty.dev) (now [Build Awesome](https://build.awesome.me/))
- Deployed with [Netlify](https://www.netlify.com/)
- Hosted at [Github](https://www.github.com)
- Versioning with Git

##### Programming Languages

- JavaScript (ESM) on the backend/server side
- Designed with CSS
- Used the [Nunjucks](https://mozilla.github.io/nunjucks/) templating language for layouts along with HTML
- Content written in Markdown parsed with [markdown-it](https://markdown-it.github.io/)
